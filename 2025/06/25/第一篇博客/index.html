使用Hexo+Github搭建博客过程中遇到的问题

问题一：在测试SSH连接的步骤中，在Git Bash窗口输入以下命令：ssh -T git@github.com，此时并没有出现欢迎提示，而是提示ssh: connect to host github.com port 22: Connection refused。

解决方法：这个错误提示的是连接github.com的22端口被拒绝了。经过查阅一些资料了解到此时可以通过更改访问端口号进行解决，在第一次遇到这个报错时，.ssh文件夹里是没有config文件，需要在该文件夹下新建一个config.txt文件，然后在空的文本文件中输入以下代码：
Host github.com
Hostname ssh.github.com
Port 443
使用CTRL+S保存退出后对该文件进行重命名，把.txt后缀删除。这样就修改好了端口号，此时再次在Git Bash窗口输入ssh -T git@github.com命令发现成功出现欢迎提示。

问题二：在博客目录下运行hexo cl && hexo g && hexo d时最后一行报错：Error Deployer not found: git。

解决方法：经过研究发现报错原因是未安装hexo-deployer-git插件，需要在博客目录下运行：npm install hexo-deployer-git –save进行下载，之后再次在博客目录下重新输入hexo cl && hexo g && hexo d即可正常运行。
